
**WorkMatch** is a job platform, unlike the traditional job platform in which the applicants need to seek and apply into the posted jobs,  the *applicants* post their *resume,cv* into the application and their *availablitiy*, the general information which is needed by the *recruiter* to give jobs. Then the *recruiter* can reach out to the *applicants* regarding the jobs they are offered in-app or via the communication method that is suitable for both parties.

The project needs to be both mobile application and web application and needs to have multi-lingual support.

# Features
#### Candidate Features
- Registration and Authentication
- Profile Builder
	- Personal Info
	- Skills
	- Experience
	- Current Visa Status
	- JLPT(*Japanese-Language Proficiency Test*)
	- Prefrences,etc
#### Recuiter Features
- Registration and Verification 
- Candidate Search with fitlers
- Profile Vieweing
- Direct Messaging and Communication
- Shortlisting
#### Additional Features
- Multi-lingual UI
- Basic Data Analysis
